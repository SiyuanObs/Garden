# 小花园 H5 · 部署成可分享的网址

H5 是纯静态页面（HTML/CSS/JS），可以放到任意静态托管上，拿到一个**所有人都能点开的网址**。

---

## 方式一：GitHub Pages（推荐，免费且稳定）

前提：项目已在 GitHub 上（例如仓库名 `Garden`）。

1. 打开仓库页面，点 **Settings** → 左侧 **Pages**。
2. 在 **Source** 里选 **Deploy from a branch**。
3. **Branch** 选 `main`（或你放代码的分支），**Folder** 选 **/ (root)**，点 Save。
4. 等一两分钟，页面会显示：`Your site is live at https://<你的用户名>.github.io/Garden/`。

**分享链接**（别人直接点开即可玩）：

```
https://<你的用户名>.github.io/Garden/h5/
```

把 `<你的用户名>` 换成你的 GitHub 用户名。例如用户名为 `wangsiyuan`，链接就是：

```
https://wangsiyuan.github.io/Garden/h5/
```

之后每次 `git push` 到该分支，页面会自动更新。

---

## 方式二：Vercel（免费，无需 GitHub 也可用）

1. 打开 [vercel.com](https://vercel.com)，用 GitHub 登录（或邮箱注册）。
2. 点 **Add New** → **Project**，选择你的 `Garden` 仓库并导入。
3. **Root Directory** 保持默认（项目根目录）即可，点 **Deploy**。
4. 部署完成后会给你一个地址，形如：`https://garden-xxx.vercel.app`。

**分享链接**：

```
https://garden-xxx.vercel.app/h5/
```

（把 `garden-xxx` 换成你实际得到的项目名。）

---

## 方式三：Netlify Drop（不用 Git，拖拽上传）

1. 打开 [app.netlify.com/drop](https://app.netlify.com/drop)。
2. 把本地的 **整个 `h5` 文件夹**（连同里面的 `index.html`、`css`、`js`、`config.js`）拖进页面。
3. 部署完成后会得到一个随机网址，如：`https://random-name-123.netlify.app`。

**分享链接**：就是这个网址，例如：

```
https://random-name-123.netlify.app/
```

（因为拖的是 `h5` 文件夹，根目录就是游戏首页，直接打开即可。）

---

## 小结

| 方式        | 分享链接示例 | 说明 |
|-------------|--------------|------|
| GitHub Pages | `https://用户名.github.io/Garden/h5/` | 需先 push 代码到 GitHub |
| Vercel      | `https://项目名.vercel.app/h5/`       | 连 GitHub 一键部署      |
| Netlify Drop | `https://随机名.netlify.app/`         | 拖拽 `h5` 文件夹即可，无需 Git |

任选一种部署后，把对应链接发给别人，即可在手机或电脑浏览器里打开玩。
