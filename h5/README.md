# 小花园 H5 版

与主项目相同逻辑的 Q 版网页版，支持手机和电脑浏览器。

## 运行方式

- **本地直接打开**：用浏览器打开 `index.html` 即可（部分功能依赖本地文件协议）。
- **推荐**：在项目根目录执行 `python -m http.server 8080`，然后访问 `http://localhost:8080/h5/`。

## 操作说明

- **空地**：点击后弹出选花菜单，选择一种花种植。
- **已种（生长中）**：点击消耗 1 滴水浇水，变为可收获。
- **可收获**：点击收获到背包并获得经验。
- **🔒 地块**：相邻已解锁的地块会显示解锁费用，点击并支付金币可解锁。
- **💧/🪙**：水与金币；点击 ➕ 可花 3 金币购买 1 滴水。
- **批量模式**：解锁 ≥2 块地后出现。开启后点击「已种」会批量浇水，点击「可收获」会批量收获。
- **订单**：右侧/下方订单可收集所需花卉后点击「送达」获得金币。

逻辑与 `garden/models.py` 及 `config/*.json` 保持一致。
